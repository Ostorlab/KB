Cisco has released software updates that address CVE-2026-76418, and there are no workarounds. The vulnerability is actively exploited (October 2026), so upgrade affected devices as a priority.

* **Upgrade to the first fixed release for your train** (ASA: 9.16.4.104, 9.18.4.96, 9.20.4.50, 9.22.3.200, 9.23.1.48, 9.24.1.27/9.24.10.1; FTD: 7.0.11, 7.2.13, 7.4.9, 7.6.7, 7.7.14, 10.0.3, 10.1.1 — or any later release). Use the Cisco Software Checker to confirm that no other advisory affects the target release before choosing the upgrade version. For FTD, follow the Secure FMC upgrade guidance for your platform.
* **If you cannot upgrade immediately, apply the mitigation**: remove secondary authentication from user-configured tunnel group lists or from the default tunnel group.
  * If `DefaultWEBVPNGroup` does **not** use secondary authentication, disable the tunnel group list (`no tunnel-group-list enable` in WebVPN configuration mode). Users will no longer be able to choose a connection profile from a provided list and must know the correct profile to use.
  * If `DefaultWEBVPNGroup` **does** use secondary authentication, remove it (`no secondary-authentication-server-group`). This lowers the security posture of remote access VPN — treat it as a temporary measure and plan the upgrade.
* **Inventory your exposure before deciding**: list every ASA/FTD device with `webvpn` enabled and check each tunnel group — including `DefaultWEBVPNGroup` — for `secondary-authentication-server-group`. Disabling the group list (`no tunnel-group-list enable`) does **not** remove exposure when the default group uses secondary authentication, so do not use the absence of the group list as evidence of safety.
* **Protect the SSL VPN service at the edge** where possible: restrict which networks can reach the remote access VPN portal, and monitor for unexpected device reloads (`show crashinfo`, syslog `%ASA-6-605005` or the FMC health events), which on a vulnerable release are the observable outcome of exploitation attempts.
* **Treat repeated unexplained reloads on a vulnerable release as an incident**: capture `crashinfo` and review connection logs to the SSL remote access VPN for crafted-connection attempts from unexpected sources, and escalate to Cisco TAC with the advisory ID (cisco-sa-asaftd-tunnel-dos-s6mgkb75) and bug ID (CSCwx26625).
